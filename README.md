# Portfolio — Dubian Ferney Amado Vargas

Sitio web estático profesional orientado a Data, BI y Automation.

## Ejecutar localmente

Opción 1: abre `index.html` directamente.

Opción 2 (recomendado):

```bash
python -m http.server 8080
```

Luego abre `http://localhost:8080`.

## Dependencias web

El sitio usa CDN para:
- Google Fonts
- Chart.js
- Leaflet
- CARTO / OpenStreetMap tiles

Requiere conexión a Internet para visualizar los gráficos y el mapa con sus librerías externas.
